# Asset attribution

Every non-code asset in this repository (fonts, icons, images, example documents) is listed here with its author, source and licence. `cargo xtask assets` (part of `cargo xtask ci`) fails if an asset file is missing from this table.

**Policy (mandatory):** Not Word contains **no proprietary Microsoft, Adobe, Avid or Autodesk artwork, templates, themes, clip art, fonts or other assets**. Every asset is original contributor work or third-party material with compatible redistribution rights (open source, public domain / CC0, or a permissive Creative Commons licence). The openly licensed Adobe-authored Source fonts below are permitted under their OFL terms. Screenshots of other vendors' software are never committed. Optional open fonts may be provided through `CRAFT_FONTS_DIR`; preserve their licence texts and attribution. The original Not Word identity replaces the upstream ArtCraft trademarked artwork; upstream code and contributor credits remain preserved in `NOTICE`, the code and this table.

Generated-in-code art is original and has no file to list: the UI icon set (`crates/ui-egui/src/icons.rs`), the sample documents and templates (`crates/engine/src/sample.rs`), the table and style previews, and theme colours (`crates/engine/src/cmd/design.rs`).
